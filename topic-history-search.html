Topic 5 — History, Search & Archiving

Six months from now, can the team find "that exchange with the supplier"? History lives in very different places depending on the option — and sometimes in several places at once.

📅 Last updated: 2026-09-08 ✍️ Chemin Neuf Community · Kimi K3 🏷️ Status: Draft — pending review

On this page

Comparison across the 7 options

Option Where History Lives Centralized Team Search Continuity on Staff Departure Key Caveats
1. Shared Password Account The shared mailbox (all inbound + sent). Yes full Gmail search for everyone At risk history survives, but so does the shared-password problem Complete history, indistinguishable per author.
2. Gmail Delegation Account The shared mailbox (all inbound + sent, per admin setting). Yes full Gmail search for all delegates Yes revoke the delegate; history untouched Best continuity story of all options.
3. Collaborative Inbox The group archive (groups.google.com); copies may also land in member inboxes. Partial Groups search is weaker than Gmail search; private replies absent Yes archive is group-owned, independent of members "Reply to author" messages leave no trace — history has holes by design.
4. Distribution List Scattered: N personal inboxes (inbound) + N personal Sent folders (outbound). No nobody can search the whole conversation Poor departing member takes their copy (unless retained otherwise) Reconstructing a full thread requires asking every member.
5. Email Alias / Redirection The single recipient's mailbox. N/A single mailbox by design Fragile tied to one person's account lifecycle Single point of failure for institutional memory.
6. "Send Mail As" Config Senders' personal Sent folders. No Poor Outbound side of 4/5 — same scattering problem.
7. Email-to-Google Chat Space The Chat Space thread history + Gmail Sent for external replies. Partial Chat search covers inbound + discussion, not the Gmail-side replies Yes Space history persists across member changes History split across two tools (Chat + Gmail).

Google Workspace for Nonprofits edition limit — no Vault

Retention policies, legal holds and eDiscovery via Google Vault are not included in the Google Workspace for Nonprofits edition (Business Starter tier). Archiving therefore relies on the architecture itself: options that keep a complete copy in a durable place (delegated mailbox, group archive) are your only retention mechanism. Upgrading editions would change this picture — flagged here as context, not as a recommendation.

User perspective

  • Search quality varies sharply. Gmail search (options 1, 2) is best in class; Groups search (3) and Chat search (7) are noticeably weaker for mail-style retrieval.
  • "I know we answered this" frustration is the daily symptom of options 4–6: the answer exists, in someone's Sent folder — find the someone first.

Administrator perspective

Web console

Group archiving ("Who can view conversations", archive toggle) is set per group. Without Vault, the admin's retention toolkit is limited to not deleting accounts and keeping group archives enabled — there is no central retention dashboard.

API & automation

The Gmail API can export mailbox content (backup-style archiving of a delegated mailbox is scriptable). Group archives are not exportable via API. Details in Topic 10 — API & Automation.
