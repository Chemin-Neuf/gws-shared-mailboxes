GWS Shared Mailboxes

A comprehensive study of pros, cons, and caveats across different Google Workspace mechanisms for sharing an email address.

Overview

In Google Workspace, there is no direct 1:1 equivalent of a Microsoft Exchange "Shared Mailbox" (which is free, multi-user, and fully integrated across Outlook apps). Administrators and teams must evaluate multiple built-in architectures: Google Groups (Collaborative Inbox), Gmail Delegation, Email Aliases / Routing, or a Dedicated User Account.

This documentation provides an objective breakdown of functional capabilities, licensing costs, security considerations (including 2FA compliance), and mobile access trade-offs. The analysis is written in English for technical teams, concluding with an executive decision framework (Synthèse managériale) in French for decision-makers.

Highlights

Google Groups

No license cost. Supports assignment and status in the web UI, but individual inboxes do not sync read/unread status across members.

Gmail Delegation

Requires 1 licensed base account. Fully synced sent/read states for up to 1,000 delegates, but limited to the desktop web interface.
